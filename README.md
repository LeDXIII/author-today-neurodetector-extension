# Author.today NeuroDetector — Browser Extension

Браузерное расширение для проверки книг с [author.today](https://author.today) на нейросетевой текст через Yandex NeuroDetector API.

>  **Порт десктопного приложения:** [LeDXIII/author-today-neurodetector](https://github.com/LeDXIII/author-today-neurodetector) — PyQt6 GUI + Selenium. Расширение заменяет десктопный клиент, не требует Python, Selenium или установки зависимостей.

---

>  **Важно:** Проверка выполняется только по **бесплатным** главам. Если книга содержит платные главы, анализ выполняется по части текста. Результат по полной книге может отличаться от показанного.

## Установка

### Chrome / Chromium-браузеры

## Использование

1. Откройте страницу книги на author.today: `https://author.today/work/NNNNNN`
2. Нажмите на иконку расширения в панели браузера
3. Нажмите **Проверить книгу**
4. Дождитесь обхода глав — таб будет переключаться между страницами
5. Результат появится в popup: AI%, Human%, вердикт

**Результаты сохраняются** в `chrome.storage.local` и привязаны к ID книги. При повторном открытии popup на той же странице — показывается последний результат.

**История проверок** — внизу popup отображается список всех проверенных книг. Клик на запись показывает её результат.

### Проверка одной главы
На странице читалки (`/reader/book_id/chapter_id`) появляется кнопка **Проверить главу** для быстрой проверки отдельной главы.

## Принцип работы


### Пошаговый алгоритм

1. **Парсинг оглавления** — со страницы `/work/{bookId}` извлекается список глав из `ul.table-of-content`. Ссылки имеют формат `/reader/{bookId}/{chapterId}`, из них извлекаются ID глав.

2. **Последовательный обход** — активный таб навигируется по каждой главе:
   - `tabs.update()` переключает таб на `/reader/{bookId}/{chapterId}`
   - Ждётся полная загрузка DOM (`status = complete`)
   - Дополнительно 8 сек на рендер Knockout.js
   - Принудительно инжектится content script через `chrome.scripting.executeScript`

3. **Извлечение текста** — content script через `MutationObserver` обнаруживает появление `#text-container` с параграфами, собирает текст `<p>` элементов и отправляет в background service worker через `chrome.runtime.sendMessage`.

4. **Детекция платных глав** — при обнаружении ключевых фраз («платный доступ», «для продолжения чтения» и т.д.) или lock-элементов обход останавливается.

5. **Yandex NeuroDetector** — весь собранный текст отправляется POST-запросом на `https://yandex.ru/lab/neurodetector/api/analyze/text`. API без авторизации, возвращает классификацию по сегментам.

6. **Хранение результатов** — каждый результат сохраняется в `chrome.storage.local` под ключом `checkHistory[bookId]`. Popup загружает результат при открытии.

## Настройки

В `background.js` можно изменить параметры:

| Параметр | По умолчанию | Описание |
|---|---|---|
| `MAX_CHAPTERS` | 20 | Максимальное количество глав для проверки |
| `DELAY_BETWEEN_CHAPTERS_MS` | 1000 | Задержка между переключением глав |
| `CHAPTER_TIMEOUT_MS` | 25000 | Таймаут на ожидание ответа от content script |

В `content.js`:

| Параметр | По умолчанию | Описание |
|---|---|---|
| Fallback timeout | 15000 | Максимальное ожидание рендера перед отправкой body-текста |

## Yandex NeuroDetector API

- **Endpoint:** `POST https://yandex.ru/lab/neurodetector/api/analyze/text`
- **Авторизация:** не требуется
- **Запрос:** `{"text": "..."}`
- **Ответ:**
  ```json
  {
    "ok": true,
    "results": {
      "stats": {
        "segments_count": 100,
        "AI_count": 10,
        "LIKELY_AI_count": 15,
        "LIKELY_HUMAN_count": 30,
        "HUMAN_count": 45
      }
    }
  }
  ```

### Вердикт

| AI% | Вердикт |
|---|---|
| ≥ 50% | Большая часть текста вероятно сгенерирована ИИ |
| ≥ 5% | Часть текста вероятно сгенерирована ИИ |
| < 5% | Текст скорее всего написан человеком |



## Дисклеймер

> Данный инструмент предназначен **только для ознакомительных целей**. Проверка текста выполняется для облегчения нейродетекции — автоматического анализа на наличие следов генерации ИИ.
>
> Результаты проверки носят **оценочный характер** и не являются юридическим заключением. Анализ выполняется только по бесплатному фрагменту произведения, который может не отражать стиль автора на всём объёме книги.
>
> Разработчик не несёт ответственности за использование данного инструмента.
