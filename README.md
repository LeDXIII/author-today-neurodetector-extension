# Author.today NeuroDetector — Browser Extension

Браузерное расширение для проверки книг с [author.today](https://author.today) на нейросетевой текст через Yandex NeuroDetector API.

> **Порт десктопного приложения:** [LeDXIII/author-today-neurodetector](https://github.com/LeDXIII/author-today-neurodetector) — PyQt6 GUI + Selenium. Расширение заменяет десктопный клиент, не требует Python, Selenium или установки зависимостей.

---

> ⚠️ **Важно:** Проверка выполняется только по **бесплатным** главам. Если книга содержит платные главы, анализ выполняется по части текста. Результат по полной книге может отличаться от показанного.

## Использование

1. Откройте страницу книги на author.today: `https://author.today/work/NNNNNN`
2. Нажмите на иконку расширения в панели браузера
3. Нажмите **Проверить книгу**
4. Дождитесь обхода глав — таб будет переключаться между страницами
5. Результат появится в popup: AI%, Human%, вердикт

**Результаты сохраняются** в `chrome.storage.local` и привязаны к ID книги. При повторном открытии popup на той же странице — показывается последний результат.

**История проверок** — внизу popup отображается список всех проверенных книг. Клик на запись показывает её результат.

**Повторная отправка** — при ошибке 429 (лимит запросов Яндекс) появляется кнопка «Повторить отправку». Не нужно перезапускать проверку — текст уже собран.

**Настройки** — во вкладке «Настройки» можно изменить количество глав, задержки и таймауты.

## Принцип работы

### Почему Selenium не нужен в расширении

Оригинальный десктопный проект использует Selenium, потому что author.today рендерит текст глав через **Knockout.js** — клиентский MVVM-фреймворк. Простой `fetch` или `httpx` возвращает пустой HTML без текста.

Расширение решает эту проблему иначе: **навигирует реальный таб** по страницам глав, дожидается рендера, и `chrome.scripting.executeScript` извлекает текст из `#text-container`.

### Пошаговый алгоритм

1. **Парсинг оглавления** — со страницы `/work/{bookId}` извлекается список глав из `ul.table-of-content`. Ссылки имеют формат `/reader/{bookId}/{chapterId}`, из них извлекаются ID глав.

2. **Последовательный обход** — активный таб навигируется по каждой главе:
   - `tabs.update()` переключает таб на `/reader/{bookId}/{chapterId}`
   - `tabs.onUpdated` отслеживает `status === 'complete'` (DOM загружен)
   - Дополнительно `renderWaitMs` (по умолчанию 4 сек) на рендер Knockout.js
   - `chrome.scripting.executeScript` напрямую забирает текст из `#text-container > p`

3. **Детекция платных глав** — при обнаружении ключевых фраз («платный доступ», «для продолжения чтения» и т.д.) или lock-элементов обход останавливается.

4. **Yandex NeuroDetector с retry** — весь собранный текст отправляется POST-запросом на `https://yandex.ru/lab/neurodetector/api/analyze/text`. При ошибке 429/5xx выполняется до 5 попыток с экспоненциальным backoff (3с → 6с → 12с → 24с → 48с).

5. **Хранение результатов** — каждый результат сохраняется в `chrome.storage.local` под ключом `checkHistory[bookId]`. Popup загружает результат при открытии.

## Настройки

Настраиваются через вкладку «Настройки» в popup. Сохраняются в `chrome.storage.local`.

| Параметр | По умолчанию | Описание |
|---|---|---|
| `maxChapters` | 20 | Максимальное количество глав для проверки |
| `delayBetweenChaptersMs` | 800 | Задержка между переключением глав |
| `renderWaitMs` | 4000 | Ожидание рендера Knockout.js после загрузки DOM |
| `chapterTimeoutMs` | 20000 | Таймаут на ожидание ответа от главы |

## Yandex NeuroDetector API

- **Endpoint:** `POST https://yandex.ru/lab/neurodetector/api/analyze/text`
- **Авторизация:** не требуется
- **Запрос:** `{"text": "..."}`
- **Ответ:**
  ```json
  {
    "ok": true,
    "results": {
      "stats": {
        "segments_count": 100,
        "AI_count": 10,
        "LIKELY_AI_count": 15,
        "LIKELY_HUMAN_count": 30,
        "HUMAN_count": 45
      }
    }
  }
  ```

### Вердикт

| AI% | Вердикт |
|---|---|
| ≥ 50% | Большая часть текста вероятно сгенерирована ИИ |
| ≥ 5% | Часть текста вероятно сгенерирована ИИ |
| < 5% | Текст скорее всего написан человеком |

## Дисклеймер

> Данный инструмент предназначен **только для ознакомительных целей**. Проверка текста выполняется для облегчения нейродетекции — автоматического анализа на наличие следов генерации ИИ.
>
> Результаты проверки носят **оценочный характер** и не являются юридическим заключением. Анализ выполняется только по бесплатному фрагменту произведения, который может не отражать стиль автора на всём объёме книги.
>
> Разработчик не несёт ответственности за использование данного инструмента.
